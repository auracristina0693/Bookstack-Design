# 06 · Referencias

Inspiración y referentes externos — todo lo que no es una decisión tomada, pero sí un insumo para tomarla.

## Qué va aquí

- **`Inspiracion/`** *(se crea cuando haya material)* — capturas, moodboards, apps o patrones de interacción que sirven de referencia.
- **`Enlaces.md`** *(se crea con el primer enlace)* — lista simple de links con una línea de contexto de por qué se guardó cada uno.

## Diferencia con `05-Investigación/`

Acá va lo que *inspira*; en Investigación va lo que se *probó con usuarios reales o datos propios*. Un mismo referente puede empezar aquí y, si se valida con research, generar un hallazgo en `05-Investigación/`.
