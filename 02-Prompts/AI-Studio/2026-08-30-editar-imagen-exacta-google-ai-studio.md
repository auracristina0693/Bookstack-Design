# Propósito

Prompt para pedirle a Google AI Studio que edite una imagen ya subida (foto o mockup) haciendo un cambio puntual, sin regenerar ni reinterpretar el resto de la imagen. Sirve para reemplazar un solo elemento (una foto, un screenshot, un ícono) manteniendo intacto el layout, composición, colores, tipografía y espaciado originales.

# Prompt

```
Use the attached image as the exact base — do not regenerate, redraw, or reinterpret it. Keep 100% of the original image unchanged: same layout, same composition, same colors, same typography, same spacing, same every other element.
The ONLY change to make is: [describe aquí específicamente qué debe cambiar — ej. "replace the screenshot in the right panel with the second image I'm attaching" o "swap only the product photo, nothing else"].
Do not alter anything outside that single element. If you cannot perform a targeted edit and would need to regenerate the full image, tell me instead of producing a new version.
```
