# 05 · Investigación

Todo lo relacionado con research de usuarios, benchmarking de referentes y métricas — el respaldo detrás de las decisiones de diseño.

## Subcarpetas propuestas (se crean cuando llegue el primer material)

- **`Research-usuarios/`** — guiones de entrevista, notas de sesiones de usabilidad, hallazgos.
- **`Benchmarking/`** — análisis de apps/productos referentes, qué hacen bien y qué no.
- **`Metricas/`** — capturas o resúmenes de métricas de producto relevantes para una decisión de diseño.

## Cómo se alimenta

Cada sesión de research o prueba de usabilidad debería dejar al menos un archivo acá con: fecha, objetivo, participantes (o fuente de la métrica), hallazgos clave y qué decisión de diseño se tomó a partir de ellos.
