# 04 · Decisiones

Registro de decisiones de diseño o arquitectura que valen la pena recordar — el tipo de cosas que, si no se anotan, se vuelven a discutir seis meses después.

Formato: [ADR](https://adr.github.io/) (Architecture/Design Decision Record), uno por archivo.

## Convención

- Nombre de archivo: `0001-titulo-corto.md`, numeración consecutiva, nunca se reutiliza un número.
- Nunca se borra una decisión: si cambia, se crea una nueva que la reemplaza y se enlazan entre sí ("reemplaza a 0001", "reemplazada por 0007").
- Plantilla base: [`0000-plantilla-adr.md`](./0000-plantilla-adr.md).
