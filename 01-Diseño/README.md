# 01 · Diseño

La fuente de verdad visual y de UX del proyecto.

## Qué va aquí

- **`Design.md`** — el archivo de diseño original del proyecto (viene de Google AI Studio). Pendiente de migrar aquí cuando conectemos la carpeta del proyecto real. Mientras tanto, sigue siendo la guía inicial.
- **`Sistema-de-diseño.md`** — tokens de color, tipografía, espaciado, componentes reutilizables. Se crea cuando empecemos a formalizar el sistema.
- **`Inventario-de-pantallas.md`** — lista de pantallas de la app, su propósito y su estado (boceto / en Figma / implementada).

## Cómo se alimenta

Cada vez que haya una decisión de diseño nueva (un flujo, un componente, un patrón de interacción), se documenta acá. Si la decisión tiene una razón detrás que vale la pena recordar, además se registra como ADR en [`04-Decisiones/`](../04-Decisiones/README.md).
