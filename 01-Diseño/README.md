# 01 · Diseño

La fuente de verdad visual y de UX — de cada proyecto que se documente aquí.

## Cómo se organiza

Si es un solo proyecto pequeño, sus archivos van directo en esta carpeta. Si hay más de un proyecto con diseño propio, cada uno vive en su propia subcarpeta: `01-Diseño/<nombre-del-proyecto>/`.

## Qué va en cada proyecto

- **`Design.md`** — el archivo de diseño original del proyecto (por ejemplo, el que viene de Google AI Studio en el primer proyecto Android). Sirve como guía inicial hasta que el sistema de diseño se formalice.
- **`Sistema-de-diseño.md`** — tokens de color, tipografía, espaciado, componentes reutilizables.
- **`Inventario-de-pantallas.md`** — lista de pantallas, su propósito y su estado (boceto / en Figma / implementada).

## Cómo se alimenta

Cada vez que haya una decisión de diseño nueva (un flujo, un componente, un patrón de interacción) en cualquier proyecto, se documenta acá. Si la decisión tiene una razón detrás que vale la pena recordar, además se registra como ADR en [`04-Decisiones/`](../04-Decisiones/README.md).
