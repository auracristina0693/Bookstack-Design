# 08 · Agentes

El contrato de cómo debe comportarse cualquier agente de IA (Claude Code, Codex, Cursor, etc.) que trabaje en este proyecto, para que el resultado sea coherente sin importar cuál se use.

## Qué va aquí

- **`AGENTS.md`** — instrucciones generales, válidas para cualquier agente: qué leer primero, qué documentar y dónde, qué no hacer.
- **`CLAUDE.md`** *(pendiente)* — instrucciones específicas si se usa Claude Code, cuando haga falta algo más particular que lo general.
- **`reglas-por-agente.md`** *(pendiente)* — diferencias puntuales de comportamiento entre agentes, si aparecen.
