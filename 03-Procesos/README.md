# 03 · Procesos

Cómo se trabaja en este proyecto, día a día.

## Qué va aquí

- **`Bitacora.md`** — diario cronológico y corto de sesiones de trabajo y decisiones. Es lo primero que debería leer un agente o una persona que retoma el proyecto después de un tiempo.
- **`Checklist-de-entrega.md`** — lo que se revisa antes de dar por cerrada una pantalla, un flujo o una entrega.
- **`Flujo-de-trabajo.md`** *(pendiente)* — el paso a paso de cómo se pasa de una idea a un prototipo, y de un prototipo a código funcional en Android. Se redacta cuando el proceso esté más asentado.
