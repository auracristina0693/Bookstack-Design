# 00 · Inicio

Punto de entrada. Si un agente o una persona nueva abre este repositorio por primera vez, este es el archivo que debería leer primero.

## Qué es esto

Esta no es la documentación de un solo proyecto — es la librería general de Cristi: un lugar donde queda registrado el proceso, las decisiones, los prompts y las referencias de **todos los proyectos** en los que trabaja. Cada libro numerado organiza la información por tipo, y cuando algo pertenece a un proyecto específico, se distingue por subcarpeta o por el nombre mencionado en la entrada (ver "Cómo conviven varios proyectos aquí" en el `README.md` raíz).
